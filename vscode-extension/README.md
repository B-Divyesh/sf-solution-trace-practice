# Show Your Debugging for VS Code

Record a hypothesis, test output, fix, and clue while you debug.

Open **Show Your Debugging: Start a Receipt** from the Command Palette or use the checkmark icon in the Activity Bar. The extension stores receipts in VS Code's local extension state. It does not read workspace files, open editors, or clipboard contents, and it makes no network requests.

A receipt records process. It does not prove competence.

See the full project documentation and privacy policy at <https://solution-trace-practice.sociobot.in/privacy>.
